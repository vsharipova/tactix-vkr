# TactiX — интеллектуальная система поддержки тренировочного процесса спортсмена-стрелка

**Студент:** Шарипова Виктория Олеговна  
**Группа:** РИС-23-3  
**Вариант:** ВКР — «Разработка интеллектуальной системы поддержки тренировочного процесса спортсмена-стрелка»  
**Постановка задачи:** Разработать интеллектуальную систему поддержки тренировочного процесса спортсмена-стрелка (практическая стрельба), развивающую существующее web-приложение «TactiX». Система должна обеспечивать учёт и анализ результатов матчей и тренировок, визуальное моделирование упражнений (брифингов), формирование персональных рекомендаций и планирование тренировочного цикла, а также включать мобильный версию с офлайн-режимом и синхронизацией и ИИ-модули (анализ видео, рекомендации по брифингу, планирование, чат-бот). Система строится по клиент-серверной архитектуре: backend на ASP.NET Core + PostgreSQL, кроссплатформенный мобильный клиент, выделенные ИИ-сервисы.

## О продукте

Интеллектуальная система для спортсменов, занимающихся практической стрельбой. Развивает существующее web-приложение «TactiX» (учёт тренировок/матчей, аналитика, брифинги) до распределённой клиент-серверной системы с мобильной версией, офлайн-синхронизацией и ИИ-модулями: анализ видео, рекомендации по прохождению упражнения, интеллектуальное планирование тренировочного цикла, ИИ-ассистент (чат-бот).
